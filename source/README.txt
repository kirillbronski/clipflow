ClipFlow для Windows

Запустите ClipFlow.exe из этой папки.
Python и отдельная установка программ не требуются.
Сохраняйте всю папку вместе: рядом с приложением находятся необходимые компоненты.

Версия 1.3.0: YouTube и GetCourse, тёмный интерфейс в стиле Material.

Весь интерфейс приложения оформлен в единой тёмной палитре:
красный primary, приглушённый розовый secondary и золотистый tertiary/accent.
Главные действия, поля, переключатели, карточки очереди и диалоги оформлены
одинаково. Системный выбор папки и файлов использует диалоги Windows.
Цветовые роли: https://m3.material.io/styles/color/the-color-system

1. Вставьте ссылку на видео YouTube или урок GetCourse.
2. Выберите папку для скачивания (по умолчанию D:\Gdrive, если она существует).
3. Выберите «Видео — MP4» и качество либо «Только звук — MP3».
4. Нажмите «Скачать».

Выбранное качество — верхняя граница разрешения. Если оно недоступно,
программа выбирает ближайшее меньшее. «Лучшее доступное» снимает ограничение.
MP4 содержит исходный видеокодек YouTube; старые плееры могут его не поддерживать.
MP3 создаётся с битрейтом 192 кбит/с.
При ссылке с плейлистом по умолчанию скачивается только указанное видео.
Для полного плейлиста YouTube включите «Плейлист YouTube целиком» и вставьте
ссылку на плейлист или видео с параметром list=… . Все доступные видео будут
скачаны по очереди в подпапку Playlist [идентификатор плейлиста].
Файлы нумеруются 001, 002 и далее в порядке плейлиста. Выбор качества и режима
MP3 применяется ко всем элементам. Состояние каждого элемента видно в очереди.
Ошибки отдельных видео не останавливают остальные; в конце показывается итог.
Закрытые/удалённые видео и плейлисты без доступа могут быть недоступны.
Папка и качество запоминаются. Кнопка «Открыть папку» показывает результат.
Отмена срабатывает при следующем обновлении загрузки; обработка FFmpeg может
сначала завершиться. Частичные файлы сохраняются для продолжения загрузки.
Закрывать приложение во время скачивания можно после его отмены.

Некоторые видео требуют входа в аккаунт или недоступны в текущей сети.
Программа покажет ошибку. Вход в YouTube в этой версии не предусмотрен.

Для закрытых уроков GetCourse нажмите «Доступ GetCourse…»:
- Brave: сначала войдите в аккаунт школы в браузере, затем полностью закройте
  Brave перед скачиванием. Некоторые версии Windows/Brave не разрешают прочитать
  сессию браузера; в этом случае выберите другой способ.
- Email и пароль: введите данные аккаунта школы в программе. Пароль хранится
  только в памяти до закрытия программы и передаётся только школе из вашей ссылки.
  Вход с одноразовым кодом или дополнительной проверкой этим способом не поддерживается.
- Файл cookies: выберите экспортированный файл Netscape cookies из авторизованного
  браузера. Программа не изменяет этот файл и не сохраняет его содержимое в настройках.
- Без входа: для открытых уроков и прямой временной ссылки плеера GetCourse.

С урока GetCourse скачивается первое доступное видео. Новые региональные адреса
плеера gceuproxy.com поддерживаются. Прямые ссылки плеера могут истекать — при
ошибке получите новую ссылку из открытого урока.
Чтобы получить её в Brave: откройте урок, нажмите F12, во вкладке Elements
найдите iframe с адресом /sign-player/ и скопируйте значение его src целиком.
Вставьте этот адрес в программу. Для него вход через «Доступ GetCourse» не нужен.

Исходный код: downloader.py. Используются yt-dlp, FFmpeg и Node.js.

Вкладки YouTube и GetCourse содержат отдельные ссылки, форматы, качество
и папки. При переключении вкладок введённые данные сохраняются в памяти.
Плейлисты — на вкладке YouTube; доступ к закрытым урокам — на вкладке GetCourse.
Новый значок используется в окне, EXE, установщике и ярлыках.
Установщик обновляет прежний YouTube Downloader с сохранением данных.
