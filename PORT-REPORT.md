# ClipFlow 1.8.4 — перенос Windows → macOS

Проверена актуальная папка Windows; перенос выполнен только в проект macOS. Контрольные суммы исходников, тестов, сборочных файлов и ресурсов Windows после работы совпадают с исходным снимком: 53 файлов, 0 изменений.

## Сопоставление модулей

| Windows | Результат в macOS |
|---|---|
| downloader.py | Перенесён актуальный интерфейс и обработка очереди/скачиваний 1.8.4; поверх сохранены macOS-пути, Command, AppKit и защита статусов. |
| instagram_media.py | Извлечение публикаций/Reels/каруселей, оригинальные фото, фильтры типов, видео/аудио. |
| instagram_session.py | Отдельные cookies и профиль Instagram в Application Support. |
| media_names.py | Общие короткие имена медиа. |
| youtube_session.py | Актуальная логика сессий; защита профиля через Keychain вместо DPAPI. |
| embedded_auth.py | Встроенный браузер входа и режим iPad; запуск отдельным процессом macOS. |

Все функции Windows downloader.py представлены в macOS; Windows protect_profile заменена общей реализацией platform_support.protect_profile. Windows-исполняемые файлы, DPAPI, шрифт Segoe UI и системные пути адаптированы под macOS. PNG YouTube/GetCourse совпадают; добавлен PNG Instagram.

## Перенесённое поведение

- Три сервиса, новые цвета, обновлённые элементы управления и справка на русском/английском.
- Instagram: Reels, посты, фото и карусели; All/Videos/Photos; MP4/MP3, пропуск фото в MP3.
- Полное описание публикации: TXT с UTF-8 BOM либо Markdown UTF-8; атомарная запись. Параметры сохраняются в задании и учитываются при поиске дубликатов. При удалении файлов удаляется связанное описание.
- Асинхронная проверка качества с задержкой 650 мс, отбрасыванием устаревших ответов, выбором лучшего качества и автоматическим скачиванием по переключателю.
- Новая папка по умолчанию Downloads/ClipFlow с подпапками сервисов, сохранение пользовательской папки, короткие названия.
- Обновлённые фазы обработки, повторные попытки и защита завершённых строк от запоздалого прогресса.
- Строка аккаунта Instagram на вкладке скрыта в исходной Windows 1.8.4; это поведение сохранено. Вход доступен через меню аккаунтов.

## Сохранённые исправления macOS

Атомарная смена цветов, кеширование иконок, фиксированная ширина статуса, обновление телеметрии без перераскладки строки, не более двух событий прогресса в секунду, сглаженная скорость по байтам, отдельный идентификатор запуска задания. Дополнительно исправлен отложенный callback CustomTkinter, который мог скрывать выбранную вкладку после быстрых переключений.
