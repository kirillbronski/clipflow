# ClipFlow для macOS

Перенос актуальной Windows-версии ClipFlow 1.8.4 с сохранением интеграции macOS и исправлений плавности интерфейса. Сборка: Apple Silicon, macOS 27+.

## Запуск

Откройте `outputs/ClipFlow-1.8.4-macOS-arm64.dmg` и перетащите приложение в Applications. Компоненты Python, Tk, PySide6, yt-dlp, FFmpeg, ffprobe и Node.js включены. Сборка имеет локальную ad-hoc подпись и не нотарифицирована Apple.

## Исходники и сборка

Основной код находится в `source/`. Оригинальная CustomTkinter 6.0.0 сохранена в `source/_internal/`. macOS-интеграция — `source/platform_support.py`. Пароли и снимки сессий шифруются Fernet; ключ находится в login Keychain под сервисом ClipFlow.

Для повторной сборки требуется Python 3.12 с Tk, FFmpeg, ffprobe и Node.js для arm64 в `/opt/homebrew/bin`. Установите зависимости из `requirements.lock` в `.venv`. Если Homebrew устанавливает расширение Tk отдельно, скопируйте `_tkinter.cpython-312-darwin.so` из `/opt/homebrew/opt/python-tk@3.12/libexec/` в `.venv/lib/python3.12/site-packages/`. Иконка `work/clipflow.icns` генерируется Pillow из `source/clipflow.png`. Затем выполните `./build-macos.sh`.

## Проверки

`CLIPFLOW_DATA_DIR=/tmp/clipflow-ui-test .venv/bin/python source/downloader.py --ui-self-test` — вкладки, очередь, дубликаты, язык, диалоги и буфер обмена.

`CLIPFLOW_DATA_DIR=/tmp/clipflow-auth-test .venv/bin/python source/downloader.py --auth-self-test /tmp/clipflow-auth-test` — Qt WebEngine, сохранение и чтение зашифрованной тестовой сессии. Те же команды поддерживает исполняемый файл готового .app.

Реальный вход в YouTube/GetCourse нужно проверить с вашим аккаунтом. Автоматические тесты не вводят реальные учётные данные.

## 1.7.1

Смена палитры на macOS выполняется атомарно через AppKit; промежуточные перерисовки Tk не выводятся на экран. Неизменившиеся цвета не перенастраиваются, иконки вкладок кэшируются. Проверено 30 переключений с 50 строками очереди (151–185 мс на переключение), включая снятие блокировки при исключении. Smoke-test готового приложения и приложения из DMG пройден.

## Исправления статусов в 1.7.2

События прогресса и ETA объединяются за один цикл интерфейса, сохраняя порядок переходов между скачиванием, обработкой и завершением. Перерисовка очереди выполняется атомарно. События привязаны к конкретному запуску задания: запоздавшая ошибка предыдущего запуска не меняет статус следующего. Русские динамические подписи сохраняют связь с Tk-переменной; английские обновляются только при изменении текста.

## 1.7.3

Строки загрузки имеют фиксированное поле статуса. Обновления прогресса не вызывают повторную настройку кнопок, фильтров, меню и раскладки очереди. Телеметрия выдаётся не чаще двух раз в секунду; скорость рассчитана по переданным байтам за интервал и сглажена. Неточное значение 100% в оценке размера не обходит ограничение частоты.

Проверены неизменные размеры статуса и строки на реальном скачивании, нулевое число вызовов раскладки при обновлении прогресса, русский и английский статус. Регрессионный тест: 3000 событий фрагментов за 3 секунды превращаются в 6 событий прогресса.

## 1.8.4 — перенос обновлений Windows

Добавлены Instagram Reels, публикации и карусели, исходное разрешение фотографий, фильтры видео/фото, сохранение полного описания TXT/MD. Параметры описания фиксируются отдельно для каждого задания. Меню аккаунтов поддерживает отдельную сессию Instagram; строка входа на самой вкладке скрыта, как в Windows 1.8.4.

Интерфейс обновлён: три вкладки с собственными цветами, кнопка скачивания около качества, автоматический выбор доступного качества и переключатель автоматического скачивания. По умолчанию файлы раскладываются по сервисам в Downloads/ClipFlow; выбранная пользователем папка сохраняется. Длинные имена сокращаются.

Сохранены Command-сочетания, Keychain, встроенные бинарники macOS, атомарная смена палитры и плавное обновление статусов. Исправлен отложенный callback вкладок CustomTkinter при быстром переключении сервисов. Подробное сопоставление и проверки — в PORT-REPORT.md.
