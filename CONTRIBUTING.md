# Работа с общим кодом

GitHub — источник актуального кода. На каждом компьютере используйте отдельную локальную рабочую копию вне синхронизируемых облачных папок.

1. Проверьте `git status`. Сохраните незавершённые изменения отдельным коммитом или stash; не перезаписывайте их.
2. На чистой main получите изменения: `git pull --ff-only`.
3. Создайте ветку: `git switch -c feature/short-name`.
4. Меняйте общий код в `source/`. Различия ОС — в `platform_support.py` и `packaging/`.
5. Выполните `python scripts/check.py`, посмотрите diff и состояние Git.
6. Сделайте осмысленный commit, затем `git push -u origin feature/short-name`.
7. После успешных проверок обеих ОС внесите ветку в main через pull request.

Коммиты и push выполняются явно после проверки результата. Установленные приложения не обновляются автоматически от коммита: для распространения нужны новые сборки.

Не отправляйте cookies, профили браузеров, пароли, SSH-ключи, `.env`, временные видео и локальные логи. Не коммитьте `.venv`, `work`, `outputs` или `.runtime`.
