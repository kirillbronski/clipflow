Добавить несколько ссылок

Одна ссылка на строку. Можно смешивать YouTube, Instagram и GetCourse — сервис определится автоматически.

Каждый пост — отдельное задание. Ошибочная строка не мешает добавить остальные. Лимит для ссылок на Instagram-профили берётся из выбранного режима профиля.
Параметры текущего сервиса сохраняются
Попробуйте: один пост → профиль → несколько ссылок; раскройте параметры, приостановите задание, переключите тему и оформление окна.
Это макет для обсуждения: данные демонстрационные, сеть и реальные загрузки не используются. История и последние N постов показывают предлагаемое поведение, а не уже проверенную реализацию.
