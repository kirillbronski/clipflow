# Вкладки типа, поиск и сортировка

Статус: дизайн подтверждён владельцем 1 ноября 2026; спецификация ждёт проверки владельцем.

## Контекст

Третий подпроект «как в 4K». У 4K над списком вкладки по типу («Все / Видео / Аудио / Плейлисты / …»), справа «10 элементов», поиск и сортировка. Внешний вид ClipFlow остаётся своим; берётся устройство.

Сейчас (`dev`, после богатых строк):

- Над списком строка вкладок статуса «Все / В работе / Готово / Ошибки» с числами (`QueuePanel._status_tabs`, `STATUSES`); числа считают строки текущего экрана (`QueueFilter.count`).
- Площадка выбирается в боковой панели (`QueueFilter.show_source`), история — там же.
- Плейлисты и профили — одна строка группы; на экране группы видны её треки (`QueueFilter.show_group`); статус работает «по содержимому»: группа видна, если подходит хотя бы один её трек.
- Порядок строк — порядок очереди; сортировки и поиска нет. Счётчик «Очередь · N заданий» стоит в заголовке.
- У заданий есть сведения (`Job.details`: длительность, автор, флаг фото), у модели — роль размера (`SizeRole`) и сводка группы (`GroupRole`).

## Цель

Одна строка над списком, как в 4K: слева вкладки типа, справа выбор статуса, число строк, поиск и сортировка. Фильтры складываются с выбором площадки. Сортировка меняет только показ, не порядок загрузки.

## Решения владельца

- Тип — вкладками слева; статус — выпадающим списком справа в той же строке (с числами, как у нынешних вкладок).
- Выбор типа, статуса и сортировки помнится, пока программа открыта; между запусками не хранится (может стать настройкой позже).

## Поведение

### Строка над списком

- Слева вкладки «Все · Видео · Аудио · Фото · Плейлисты» (вид как у нынешних вкладок статуса), без чисел.
- Справа по порядку:
  - кнопка статуса — текст «Все 12 ▾» (выбранный статус и его число); меню «Все N / В работе N / Готово N / Ошибки N» с галочкой у выбранного; числа — как сейчас: строки текущего экрана при текущих типе, площадке и поиске;
  - «12 элементов» — число строк, видимых сейчас (с учётом всех фильтров и поиска), со склонением («1 элемент / 2 элемента / 5 элементов»; en «1 item / 5 items»);
  - кнопка поиска «🔍» (значок);
  - кнопка сортировки «⇅» с меню.
- Строка стоит там же, где сейчас вкладки статуса; экран группы («← Назад …») остаётся под ней.
- Узкое окно: вкладки и правая часть не налезают друг на друга; при нехватке места число элементов прячется первым.

### Тип задания

- «Аудио» — `options.format == 'mp3'` (в том числе YouTube Music).
- «Фото» — `details.photo`, либо Instagram с фильтром «только фото».
- «Видео» — остальные задания, кроме групп.
- «Плейлисты» — строки групп (плейлисты YouTube, профили Instagram, любые задания с потомками).
- В общем списке во вкладках «Видео / Аудио / Фото» группа видна, если в ней есть хотя бы один трек этого типа (как статус); одиночные задания — по своему типу. Во вкладке «Плейлисты» видны только группы. На экране группы вкладка типа оставляет только треки этого типа; «Плейлисты» там показывает все треки.

### Поиск

- Щелчок по «🔍» или ⌘F / Ctrl+F раскрывает поле поиска на месте числа элементов и ставит в него курсор; подсказка в пустом поле «Поиск по названию, автору и ссылке».
- Совпадение — подстрока без учёта регистра, «ё» = «е», пробелы по краям не важны. Ищется в названии строки (как показано), авторе (`details.author`) и ссылке (`canonical_url`).
- Список фильтруется по мере ввода. Группа видна, если совпадает она сама или хотя бы один её трек; на экране группы поиск фильтрует треки.
- Esc в поле — очистить и свернуть; пустое поле при потере фокуса сворачивается, поле с текстом остаётся раскрытым.
- Ничего не найдено — в списке надпись «Ничего не найдено» вместо пустоты.

### Сортировка

- Меню «⇅»: «По дате добавления» (по умолчанию — порядок очереди), «По названию», «По размеру», «По длительности» — один выбран (галочка); отдельный пункт-галочка «По убыванию»; внизу серая подсказка «Порядок загрузки не меняется».
- Название — как показано в строке, без учёта регистра, «ё» = «е», естественный порядок чисел («Урок 2» раньше «Урок 10»).
- Размер — реальный размер файлов, иначе ожидаемый (`details.size_bytes`), иначе неизвестен; у группы — сумма её треков.
- Длительность — `details.duration`; у группы — сумма известных длительностей треков.
- Строки с неизвестным значением идут в конце при любом направлении; при равенстве — порядок очереди.
- На экране группы сортировка действует на треки.
- Кнопка «⇅» подсвечена, когда выбран не порядок по умолчанию.

### Прочее

- Выбор площадки или истории в боковой панели сохраняет тип, статус, поиск и сортировку.
- Двойной щелчок, Enter, меню «⋮» и выделение работают как раньше; при смене фильтров выделение со скрывшихся строк снимается.

## Устройство

- `application/queue_view.py` (без Qt): `job_kind(job) -> str` ('video' | 'audio' | 'photo'); `normalize(text) -> str` (casefold, ё→е, strip); `natural_key(text) -> tuple`.
- `ui/queue_model.py`: `QueueFilter` получает `kind` ('all' | 'video' | 'audio' | 'photo' | 'playlists'), `query` и ключ сортировки; `show_kind`, `show_query`, `sort_by(key, descending)`; совпадения по содержимому групп — через уже имеющиеся `members`; сортировка — `lessThan` по ролям модели (новые `DurationRole`, `KindRole` при необходимости; размер — `SizeRole` и сводка группы). Подсчёт `count(status)` учитывает тип и поиск.
- `ui/queue_toolbar.py` (новый): `QueueToolbar(QWidget)` — вкладки типа, кнопка статуса с меню, число элементов, поле поиска, кнопка сортировки с меню; сигналы `kind_changed(str)`, `status_changed(str)`, `query_changed(str)`, `sort_changed(str, bool)`; `set_counts(dict)`, `set_visible_count(int)`. `QueuePanel` заменяет им `_status_tabs` и связывает сигналы с `QueueFilter`.
- `ui/window_menus.py` / `window.py`: сочетание ⌘F / Ctrl+F (`QKeySequence.StandardKey.Find`).
- `ui/i18n.py`: ключи вкладок типа, элементов (склонения), подсказки поиска, пунктов сортировки, «Ничего не найдено».
- Хранение очереди и настроек не меняется.

## Тесты

- `job_kind` для MP3, YouTube Music, фото Instagram (флаг и фильтр), обычного видео; `normalize` (регистр, ё/е, пробелы); `natural_key` («Урок 2» < «Урок 10»).
- Фильтр: каждая вкладка типа на смешанной очереди с группами (по содержимому), на экране группы; сочетание с площадкой, статусом и поиском; числа в меню статуса и «N элементов».
- Поиск: название, автор, ссылка, ё/е, регистр, совпадение только в треке показывает группу; Esc очищает; ⌘F/Ctrl+F фокусирует; «Ничего не найдено».
- Сортировка: каждый ключ в обе стороны, неизвестные в конце, равные — порядок очереди, группы по сумме; порядок загрузки (`repository.list()` и запуск очереди) не меняется.
- Узкое окно: нет горизонтальной прокрутки, строка не налезает.
- Скорость: 2000 заданий — смена вкладки, ввод символа поиска и смена сортировки не читают базу и укладываются в 0,5 с каждая.

## Вне подпроекта

Верхняя панель быстрых настроек и «умный режим» (подпроект 4); новые настройки YouTube (5). Вкладки «Каналы / Подписки / ИИ» из 4K — не нужны. Сохранение выбора между запусками — позже, отдельной настройкой.
