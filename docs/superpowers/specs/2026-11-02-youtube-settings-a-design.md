# Настройки как в 4K, часть 5а

Статус: дизайн подтверждён владельцем 1 ноября 2026; спецификация ждёт проверки владельцем.

## Контекст

Последний подпроект «как в 4K» — новые возможности из настроек 4K. Владелец взял все четыре группы; подпроект разбит на 5а (эта спецификация: плейлисты, субтитры, скорость, уведомления, сон, скрытие скачанного) и 5б (одновременные загрузки, отдельно — меняет планировщик и исполнитель). После 5б — новая версия и сборки.

Сейчас (`dev`):

- «Настройки» по разделам (`SettingsPage`: «Основные», «Авторизация», «О программе»); строка настройки — `add_toggle` / `add_choice`; новый раздел добавляется в `SECTIONS`.
- `AppSettings` (`settings-v2.json`): тема, язык, `auto_start`, `smart_mode`, пресеты площадок, последние папки, лимит профиля; поле без значения в файле читается по умолчанию, неверное — настройки по умолчанию.
- Опции yt-dlp собирает `MediaPipeline._options` (`providers/media.py`) из `DownloadOptions` задания и `ExecutionContext`.
- Дочерние задания плейлиста добавляет `Scheduler._on_discovered`: дубликаты отсекаются по `request_key` (в ключе — позиция в плейлисте, так что тот же ролик из другого плейлиста или скачанный отдельно качается снова).
- Группа (плейлист) и её сводка — `application/groups.py`, `JobListModel`; «История» — `QueueFilter.history`.

## Цель

Семь настроек из 4K, разложенные по новым разделам «Дополнительные», «Соединение», «Уведомления»; все выключены по умолчанию (скорость — без ограничений), хранятся в `settings-v2.json`, старый файл читается.

## Решения владельца

- Берутся все четыре группы; одновременные загрузки — отдельно, в 5б.

## Поведение

### Раздел «Дополнительные»

1. **«Пропускать уже скачанное в плейлистах»** (пояснение «Трек, который уже скачан в этом формате, не ставится в очередь снова»). Включено — при разборе плейлиста трек не добавляется, если есть завершённое задание того же ролика (площадка + `canonical_id`) с тем же форматом (`format`, `max_height`), чьи файлы все на месте. Позиция в плейлисте и папка не важны. Выключено — как сейчас.
2. **«Создавать файл .m3u для плейлиста»** (пояснение «Список треков по порядку рядом с файлами, для плееров»). Включено — когда у группы-плейлиста YouTube не осталось незавершённых треков и есть хотя бы один скачанный, в общей папке её файлов (как «Открыть папку» группы) пишется `<название плейлиста>.m3u8` (UTF-8): `#EXTM3U`, затем для каждого скачанного трека по порядку `playlist.index` — `#EXTINF:<секунды или -1>,<название>` и путь к файлу относительно файла списка (прямые слэши). Файл перезаписывается атомарно при каждом новом завершении (после повтора неудачных — список полнее). Имя безопасное (те же правила, что для файлов треков); если файлов в разных папках без общей внутри папки загрузки — список не пишется. Удаление файлов группы удаляет и её `.m3u8`.
3. **«Встраивать субтитры»** (пояснение «Если у ролика есть субтитры, они вшиваются в видео») и под ним выбор языка «Язык ролика / Русский / Английский» (`add_choice`, виден только при включённом тумблере). Включено — для YouTube-видео (не MP3) yt-dlp получает `writesubtitles=True`, `writeautomaticsub=False`, `subtitleslangs=[язык]` (для «Язык ролика» — исходный язык ролика из `info['language']`, иначе первый доступный), постобработчик `FFmpegEmbedSubtitle`; отсутствие субтитров не ошибка. Instagram и GetCourse — без изменений.
4. **«Не давать компьютеру засыпать во время загрузок»**. Включено — пока идёт активная работа (загрузка или обработка; ожидание лимита Instagram не считается), система не уходит в сон: macOS — дочерний `caffeinate -i -w <pid программы>`, завершаемый, когда работа кончилась; Windows — `SetThreadExecutionState(ES_CONTINUOUS | ES_SYSTEM_REQUIRED)` и сброс `ES_CONTINUOUS` по окончании. Ошибка запуска защиты не мешает загрузкам и не показывается.
5. **«Убирать скачанное из списка»** (пояснение «Готовые загрузки остаются в «Истории»»). Включено — в «Все загрузки» и в разделах площадок не показываются завершённые одиночные задания и группы, в которых все треки завершены успешно; «История» показывает всё как раньше; счётчики боковой панели и «N элементов» считают видимое.

### Раздел «Соединение»

6. **«Скорость»** — выбор «Без ограничений / 1 МБ/с / 2 МБ/с / 5 МБ/с / 10 МБ/с» (пояснение «Ограничьте, если загрузка мешает другим программам в сети»). Значение передаётся yt-dlp как `ratelimit` (байты/с) для всех площадок, включая фото Instagram; действует с начала следующей загрузки (идущая не меняет скорость). Хранится между запусками.

### Раздел «Уведомления»

7. **«Сообщать о завершении загрузок»** (пояснение «Системное уведомление, когда очередь закончилась»). Включено — когда очередь перешла от работы к простою и за этот заход что-то закончилось, показывается системное уведомление «ClipFlow — загрузки завершены» с текстом «Скачано: N» (и «, с ошибкой: M», если были ошибки); отменённые не считаются. Окно в фокусе — уведомление всё равно показывается (как у 4K). Нет поддержки системных уведомлений — ничего не происходит.

### Общее

- Новые разделы появляются в списке слева между «Основные» и «Авторизация»: «Дополнительные» (значок «☰»), «Соединение» («◎»), «Уведомления» («🔔»).
- Все новые поля `AppSettings` с безопасными значениями по умолчанию; файл без них читается; неверное значение — настройки по умолчанию (как у прочих полей).

## Устройство

- `infrastructure/settings.py`: поля `skip_downloaded: bool`, `playlist_m3u: bool`, `subtitles: str | None` (`None` — выкл., `'original' | 'ru' | 'en'`), `keep_awake: bool`, `hide_completed: bool`, `rate_limit: int | None` (байты/с из набора 1/2/5/10 МБ), `notify_done: bool`.
- `providers/base.py` / `ExecutionContext`: поле `preferences: DownloadPreferences` (`rate_limit`, `subtitles`) — неизменяемое значение, которое исполнитель берёт у презентера при старте каждой работы (`executor.preferences = …`).
- `providers/media.py`: `_options` добавляет `ratelimit` и параметры субтитров по `context.preferences`.
- `application/scheduler.py`: `skip_downloaded` (атрибут, задаётся презентером); `_on_discovered` при нём сравнивает «ролик + формат» с завершёнными заданиями с файлами на месте.
- `application/playlists.py` (новый, без Qt): `m3u_text(entries, base) -> str` и `m3u_path(group_title, folder) -> Path`; запись — в `infrastructure` (атомарно, как настройки).
- `infrastructure/keep_awake.py`: `KeepAwake.hold()` / `release()` по ОС; `ui/presenter`: включает/выключает по занятости исполнителя.
- `ui/presenter.py`: сигнал `queue_finished(int, int)` по переходу «работа → простой» с подсчётом завершённых за заход; вызов записи `.m3u8` при завершении трека группы.
- `ui/window.py`: уведомление через `QSystemTrayIcon.showMessage` (иконка приложения, невидимая в трее до первого уведомления) — при `notify_done`.
- `ui/queue_model.py`: `QueueFilter.hide_completed`.
- `ui/settings_page.py`: три раздела и семь строк; `ui/i18n.py`: тексты ru/en.

## Тесты

- Настройки: каждое поле туда-обратно, старый файл без полей, неверные значения.
- Пропуск скачанного: тот же ролик в формате MP4 уже скачан (файлы есть) → в новом плейлисте не добавлен; файлы удалены или другой формат/высота → добавлен; выключено → добавлен.
- `.m3u8`: текст по порядку `playlist.index`, относительные пути с «/», `#EXTINF` с длительностью или -1, кириллица; запись после последнего завершения, перезапись после повтора, не пишется при выключенной настройке, при разных папках без общей, удаляется вместе с файлами группы.
- Субтитры и скорость: `_options` содержит `ratelimit` и субтитры по настройкам; MP3 и Instagram — без субтитров; «Язык ролика» берёт `info['language']`.
- Сон: `KeepAwake` с подменённым запуском процесса / `SetThreadExecutionState` — держит при работе, отпускает при простое и при закрытии программы; выключено — не вызывается.
- Уведомление: переход к простою с 3 завершёнными и 1 ошибкой → один вызов `showMessage` с «Скачано: 3, с ошибкой: 1»; только отменённые → нет вызова; выключено → нет вызова.
- Скрытие скачанного: одиночное завершённое и полностью скачанная группа скрыты в «Все загрузки» и площадках, видны в «Истории»; группа с ошибкой или незавершённым треком видна; счётчики.
- Разделы настроек: порядок, тексты ru/en, язык субтитров виден только при включённом тумблере.

## Вне подпроекта

Одновременные загрузки (5б). «Показывать все видеокодеки», «Искать аудио-теги», «Отправлять статистику», ИИ, прокси, бета-версии, автообновление, автозапуск при входе в систему — не берутся.
