# Богатые строки и меню строки

Статус: дизайн подтверждён владельцем 1 ноября 2026; спецификация ждёт проверки владельцем.

## Контекст

Второй подпроект «как в 4K». В 4K Video Downloader строка очереди — обложка слева, название, под ним «2:00:18 · 895,1 MB · MP4 · 1080p · 30fps · Resonance Music Academy», справа папка и «⋮» с меню «Показать в Finder / Скопировать адрес ссылки / Открыть ссылку в браузере / … / Удалить». Внешний вид ClipFlow остаётся своим; берётся устройство.

Сейчас (`dev`, после настроек по разделам):

- Строка (`QueueDelegate`): значок площадки 47×54 (`▷` или `▧`), название, вторая строка — настройки загрузки (`meta_text`: «YouTube · MP4 · лучшее качество»), справа статус и две кнопки: «↗/Ⅱ/▷» и «×» (отмена).
- Правый щелчок (`WindowDialogs.history_menu`): открыть папку, повторить, убрать из списка, удалить файлы. У строки группы — групповое меню (`group_menu`).
- Сведения о файле (длительность, разрешение, fps, автор, обложка, размер до скачивания) не сохраняются; yt-dlp отдаёт их в `info` при разборе (`MediaItem.info`), провайдер пока сообщает только название (`TitleChanged`).
- Задание хранится в `queue.sqlite3` как JSON (`repository._encode/_decode`); фоновая подгрузка названий (`TitleNamer` → `executor.request_title` → `run_title`) идёт по одной, с паузой.

## Цель

Строка показывает обложку и сведения о самом файле, как в 4K; меню «⋮» на строке даёт показать файл, скопировать и открыть ссылку, повторить, отменить, убрать и удалить. Старая очередь читается без изменений.

## Решения владельца

- Обложки нужны и кешируются в папке данных программы; удалили задание — удалилась обложка.
- Меню «⋮» как в 4K; то же меню по правому щелчку; групповое меню получает «Скопировать ссылку» и «Открыть в браузере».

## Поведение

### Сведения о файле

- Новое неизменяемое значение `MediaDetails`: `duration` (секунды, float > 0), `width`, `height` (int > 0), `fps` (float > 0), `author` (строка до 200 символов, пробелы схлопнуты), `thumbnail` (адрес `https`), `size_bytes` (ожидаемый размер, int > 0). Любое поле может отсутствовать; неверные значения из `info` отбрасываются, а не ломают задание.
- Источник — словарь yt-dlp/Instagram: длительность `duration`; размеры `width`/`height` (у фото Instagram — размеры картинки); `fps`; автор — первое непустое из `uploader`, `channel`, `uploader_id` (у Instagram с «@»); обложка — `thumbnail`, иначе самая подходящая из `thumbnails` (ширина ближе всего к 320, но не меньше 160), у фото Instagram — адрес самой картинки; размер — `filesize`, иначе `filesize_approx`.
- Когда известны:
  - при скачивании — провайдер сообщает событие `DetailsFound(details)` рядом с первым `TitleChanged` (`MediaDownloader._save`); у задания плейлиста/профиля — по данным списка (обложка и автор плейлиста);
  - для ожидающих заданий — фоновая подгрузка названия возвращает и сведения из того же запроса, без лишних обращений к сайту.
- Сведения сохраняются в задании (`Job.details`), в JSON под ключом `details`; задание без ключа читается как `details = None`. Повтор задания (`repeat`) сведения сохраняет.

### Обложки

- Когда у задания появился адрес обложки, а файла обложки нет, она ставится в фоновую очередь загрузок обложек: по одной за раз, отдельно от скачивания и от подгрузки названий.
- Загрузка: только `https`, таймаут 15 с, не больше 2 МБ, ответ должен разбираться как картинка. Картинка обрезается по центру до 16:9 и уменьшается до 160×90, сохраняется JPEG в `<папка данных>/thumbnails/<id задания>.jpg` атомарно (временный файл и замена).
- Неудача (сеть, размер, не картинка) запоминается на время запуска, повторной попытки до перезапуска нет; строка остаётся со значком площадки. Ошибка не показывается.
- Обложка удаляется, когда задание убрано из списка любым путём (убрать, очистить очередь/историю/всё). При запуске файлы обложек, чьих заданий нет в очереди, удаляются.
- Отрисовка берёт обложку из кеша в памяти (`QPixmap` по id, сбрасывается при смене файла); строка без обложки рисуется сразу, без ожидания.
- Группа: обложка самого задания-родителя, иначе обложка первого её потомка с обложкой.

### Строка

- Слева вместо значка 47×54 — обложка 80×45 со скруглением 6 и полупрозрачным кругом с «▷» посередине (у фото — без «▷»). Нет обложки — прежний значок площадки той же ширины 80.
- Вторая строка (части через ` · `), если сведения есть:
  - видео: длительность · размер · формат · высота «1080p» · «30fps» · автор;
  - MP3: длительность · размер · «MP3» · автор;
  - фото Instagram: «Фото» · «1080×1350» · автор;
  - длительность: «M:SS», от часа «H:MM:SS»; fps округляется до целого; размер — как в группах (`size_text`): у завершённого задания — сумма реальных файлов, иначе ожидаемый со знаком «≈ »; отсутствующие части пропускаются.
- Сведений нет — прежний текст `meta_text`. Ошибка — по-прежнему красный текст причины вместо сведений.
- Строки групп оставляют свою сводку; меняется только левая часть (обложка).

### Кнопки и меню строки

- Справа у обычной строки две кнопки: основная («↗» у завершённого — показать файл, «Ⅱ» у идущего, «▷» у остальных — как сейчас) и «⋮». Кнопка «×» уходит в меню.
- «⋮» (и правый щелчок по строке) открывает меню:
  1. «Показать в Finder» (Windows: «Показать в Проводнике») — включено, если есть файлы; открывает папку с выделенным файлом (как сейчас `open_result`);
  2. «Скопировать ссылку» — `link.canonical_url` в буфер обмена;
  3. «Открыть ссылку в браузере» — `QDesktopServices.openUrl` с тем же адресом;
  4. разделитель; «Повторить» — включено у завершённых, отменённых и ошибочных; «Отменить» — включено у незавершённых;
  5. разделитель; «Убрать из списка», «Удалить файлы…» — с прежними условиями включения.
- Выделено несколько строк: пункты 1–3 действуют на строку под курсором, остальные — на всё выделение, как сейчас.
- Групповое меню получает «Скопировать ссылку» и «Открыть ссылку в браузере» (адрес плейлиста/профиля) после «Открыть папку».
- Тексты пунктов — через `i18n`, ru и en.

## Устройство

- `domain/models.py`: `MediaDetails`; поле `Job.details: MediaDetails | None = None`.
- `domain/events.py`: `DetailsFound(details: MediaDetails)`.
- `providers/details.py`: `details_from_info(info: Mapping, kind: str, service: Service) -> MediaDetails | None` — чистая функция разбора и проверки.
- `providers/media.py`, `providers/youtube.py` (+ профиль Instagram): испускают `DetailsFound`.
- Подгрузка названий: `run_title` и `request_title` возвращают пару (название, сведения); `TitleNamer` сохраняет обе.
- `application/scheduler.py`: `set_details(job_id, details)` и обработка `DetailsFound` так же, как `TitleChanged`.
- `infrastructure/repository.py`, `serialization.py`: кодирование `details`.
- `infrastructure/thumbnails.py`: `ThumbnailStore(directory)` — `path(id)`, `exists(id)`, `save(id, data: bytes)`, `remove(ids)`, `prune(keep_ids)`; без Qt.
- `ui/presenter_thumbnails.py`: `ThumbnailLoader` — очередь, загрузка в `QThreadPool` по одной, проверка и уменьшение через `QImage`, сохранение через `ThumbnailStore`, сигнал `thumbnail_ready(id)`; кеш `QPixmap` для делегата.
- `ui/job_status.py`: `details_text(job, size, tr) -> str | None`.
- `ui/queue_delegate.py`: обложка, «⋮», действие `'row_menu'` вместо `'cancel'`.
- `ui/window_dialogs.py`: общее меню строки для «⋮» и правого щелчка; новые пункты в групповом меню.
- `ui/i18n.py`: ключи пунктов меню, «Фото» уже есть.

## Тесты

- Разбор: полные `info` YouTube, MP3, фото и видео Instagram, плейлист; мусорные значения (строки, отрицательные, `nan`, `http`-адрес) отбрасываются; выбор из `thumbnails`.
- Хранение: задание со сведениями туда-обратно; старая запись без `details` читается; повтор сохраняет сведения.
- События: `DetailsFound` при скачивании сохраняется в задании; подгрузка названия сохраняет сведения ожидающего задания.
- Обложки (поддельный загрузчик): успешная загрузка даёт файл 160×90; больше 2 МБ, не картинка, `http`, таймаут — файла нет и повтора нет; удаление задания удаляет файл; запуск удаляет сиротские файлы; одновременно идёт одна загрузка.
- Текст: все варианты второй строки на ru и en, «≈» до скачивания, реальный размер после.
- Строка: обложка рисуется при наличии и не рисуется без неё; кнопки «⋮» и основная испускают свои действия; «×» больше нет.
- Меню: каждый пункт, условия включения, копирование в буфер, открытие браузера (подмена `QDesktopServices.openUrl`), несколько выделенных строк, групповое меню.
- Скорость: очередь из 1000 заданий с обложками и сведениями отрисовывается без загрузки файлов в `paint` (кеш), прежние пороги «Остановить всё»/«Очистить всё» не ухудшаются.

## Вне подпроекта

Вкладки «Видео / Аудио / Плейлисты», поиск и сортировка (подпроект 3); верхняя панель и умный режим (4); настройки YouTube (5). Обработка ИИ, «Скачать @канал», «Вставить ссылку» из меню 4K — не нужны. Обложка, встроенная в сам файл (тег), — не в этом подпроекте.
