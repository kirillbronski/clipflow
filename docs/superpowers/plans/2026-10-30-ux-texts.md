# UX и тексты — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** строка задания показывает причину ошибки и честную мета-строку; кнопки и меню очереди переименованы, символы стали иконками; тексты интерфейса вычищены по спецификации.

**Architecture:** новый модуль `ui/job_status.py` превращает код ошибки и параметры задания в текст; делегат и модель списка только рисуют/отдают его. Иконки кнопок рисуются из символа функцией `glyph_icon` в `ui/themes.py`. Все тексты — в `ui/i18n.py`.

**Tech Stack:** Python 3.12, PySide6 (Qt Widgets), pytest-qt, ruff 0.17.3.

**Spec:** `docs/superpowers/specs/2026-10-30-ux-texts-design.md`

## Global Constraints

- Все RU/EN тексты — дословно из таблиц спецификации; каталоги RU и EN имеют одинаковые ключи.
- Поведение очереди, кнопок и меню не меняется; макет окна меняется только удалением подвала.
- Внутренние ключи режимов входа (`'Обычный Qt WebEngine'`, `'Chrome на iPad · 51'`, `'Chrome на iPad · 87'`) не менять.
- Версию не поднимать, сборок нет (решение владельца до конца всей чистки).
- Код проходит `ruff format --check` и `ruff check`; `# noqa` только с кодом и причиной.
- Коммиты в `dev`, push в `origin/dev`; `main` не трогать.
- Проверка задачи: `CLIPFLOW_DATA_DIR=<временная папка> .venv/bin/python -m pytest -q <тесты задачи>`; в конце — полный `PATH=/opt/homebrew/bin:$PATH .venv/bin/python scripts/check.py` → `All offline Qt checks and coverage gates passed.`

## Review Focus

1. Старая запись `FAILED` без `job.error` (`None`) → строка показывает текст группы internal, без исключения — тест в Task 1.
2. Смена языка при видимых строках с ошибкой → причина и подсказка на новом языке — тест в Task 2.
3. Составной код карусели с неизвестной причиной или битым номером (`instagram_item_failed:abc:x`) → текст internal без исключения — тест в Task 1.
4. Смена темы → иконки кнопок перерисованы новым цветом — тест в Task 3.
5. Узкое окно (880 px) → длинная причина ошибки обрезается многоточием, полный текст в подсказке — тест в Task 2.
