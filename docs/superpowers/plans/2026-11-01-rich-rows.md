# Богатые строки и меню строки — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Строка очереди как в 4K — обложка, «длительность · размер · формат · 1080p · 30fps · автор» — и меню «⋮» (показать, скопировать/открыть ссылку, повторить, отменить, убрать, удалить).

**Architecture:** Провайдеры разбирают `info` в неизменяемое `MediaDetails` и сообщают событием `DetailsFound`; планировщик сохраняет его в `Job.details` (JSON очереди). Обложки качает `ThumbnailLoader` (Qt, по одной) и хранит `ThumbnailStore` (без Qt) в `<данные>/thumbnails/`. Делегат берёт обложку из кеша `QPixmap` через роль модели; меню строки — общее для «⋮» и правого щелчка.

**Tech Stack:** Python 3.12, PySide6, yt-dlp, pytest + pytest-qt, ruff 0.17.3.

**Spec:** `docs/superpowers/specs/2026-11-01-rich-rows-design.md`

## Global Constraints

- Старая очередь (без ключа `details`) читается без изменений; `user_version` и схема таблицы не меняются.
- `MediaDetails`: `duration: float | None`, `width: int | None`, `height: int | None`, `fps: float | None`, `author: str | None` (≤200 символов, пробелы схлопнуты), `thumbnail: str | None` (только `https`), `size_bytes: int | None`; числа > 0, конечные; неверное значение — `None`, не исключение.
- Обложка: `https`, таймаут 15 с, ≤ 2 МБ (2 097 152 байт), разбирается как картинка, обрезка по центру до 16:9, 160×90, JPEG, атомарная запись, файл `<данные>/thumbnails/<id>.jpg`; одна загрузка за раз; неудача — без повтора до перезапуска.
- В строке обложка 80×45, скругление 6; без обложки — значок площадки, левая колонка всё равно 80.
- Вторая строка: части через `SEPARATOR` (` · `); длительность «M:SS» / «H:MM:SS»; fps округлён до целого «30fps»; высота «1080p»; размер — `size_text`; до завершения ожидаемый размер с префиксом «≈ »; фото — «Фото · 1080×1350 · автор» (ключ `photo` уже есть); MP3 — «длительность · размер · MP3 · автор».
- Меню строки (ключи i18n и тексты): `row_menu.reveal` «Показать в Finder» (macOS) / `row_menu.reveal_windows` «Показать в Проводнике» (иначе), en «Show in Finder» / «Show in Explorer»; `row_menu.copy_link` «Скопировать ссылку» / «Copy link»; `row_menu.open_link` «Открыть ссылку в браузере» / «Open link in browser»; `row_menu.repeat` «Повторить» / «Repeat»; `row_menu.cancel` «Отменить» / «Cancel download»; дальше существующие `remove_list`, `delete_files`.
- Пороги скорости из прошлых подпроектов («Остановить всё»/«Очистить всё» на 700 заданиях) не ухудшаются; в `paint` нет чтения файлов.
- Покрытие: ядро ≥95 % строк / ≥90 % ветвлений, программа ≥90 % (`scripts/check.py`).
