# Панель быстрых настроек и умный режим — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Чипы «тип · качество · папка» и тумблер «💡 Умный режим» в строке карточки «Скачать»; при умном режиме вставка ссылки сразу ставит её в очередь и запускает загрузку.

**Architecture:** Настройка `AppSettings.smart_mode`; `presenter.smart_submit` поверх существующих `preview(mode='batch')` и `submit`; `QuickBar` — чипы-зеркала полей composer (меню строится из пунктов `QComboBox` при показе, выбор ставит индекс в поле); перехват вставки — подкласс поля ссылки с `paste()` и общий `Composer.paste_text`.

**Tech Stack:** Python 3.12, PySide6, pytest + pytest-qt, ruff 0.17.3.

**Spec:** `docs/superpowers/specs/2026-11-01-quick-bar-design.md`

## Global Constraints

- `AppSettings.smart_mode: bool = False`; отсутствует в файле → `False`; не-bool → `ValueError('invalid_smart_mode')` (как `invalid_auto_start`); схема `settings-v2` не меняется.
- Умный режим: `preview(text, presets, mode='batch', profile_limit=settings.profile_limit)` → `submit` → при `added` запуск очереди (как `start_queue`), независимо от `auto_start`; нераспознанные строки возвращаются в поле через `\n`.
- Тексты (ru / en): `smart_mode` «Умный режим» / «Smart mode»; `smart_mode_hint` «Вставленная ссылка сразу добавляется в очередь и скачивается с текущими настройками.» / «A pasted link joins the queue and downloads at once with these settings.»; `smart_added` «Добавлено: {count}» / «Added: {count}»; `smart_existing` «уже в очереди: {count}» / «already queued: {count}»; `choose_folder_menu` «Выбрать папку…» / «Choose folder…»; `more_parameters` «Другие параметры» / «More options».
- Сообщение «Добавлено…» видно 3 с.
- Чип «Тип» — YouTube: зеркало `format_box` (MP4 / MKV / WebM / Аудио MP3); Instagram: зеркало `filter_box`; GetCourse: скрыт. Чип «Качество» — зеркало `quality_box`, скрыт, когда поле выключено (MP3, только фото). Чип «Сохранить в» — «…/<имя папки>», подсказка — полный путь; меню — пункты `recent_box`, разделитель, «Выбрать папку…» (`_choose_folder`).
- Строка не раздвигает окно (минимальная ширина и «широкие шрифты», как в `test_wide_fonts_never_widen_the_window`).
- Покрытие: ядро ≥95 % строк / ≥90 % ветвлений, программа ≥90 %.

## Review Focus

1. Вставка многострочного текста, где есть ссылки разных площадок и мусор: распознанные добавлены со своими настройками, мусор вернулся в поле — тест `test_smart_paste_mixed_text` (Task 3).
2. Вставка той же ссылки второй раз: ничего не дублируется, сообщение «уже в очереди» — тест `test_smart_paste_duplicate` (Task 3).
3. Умный режим выключили посреди работы — следующая вставка снова просто кладёт текст в поле — тест `test_smart_off_pastes_plainly` (Task 3).
4. Смена площадки в боковой панели: чипы сразу показывают её настройки, выбор в чипе сохраняется для неё, а не для прежней — тест `test_chips_follow_service_change` (Task 2).
5. Очень длинный путь папки (вложенность > 10 уровней, кириллица): чип показывает «…/<папка>», не растягивает строку — тест `test_folder_chip_long_path` (Task 2).
