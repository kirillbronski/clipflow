## Принятые решения

Ubuntu22.04+ x86-64/glibc2.35; Ubuntu24.04+ ARM64/glibc2.39; Fedora40+ обе архитектуры.
ARM baseline явно согласован владельцем из-за PySide6 ARM wheel. GLIBC gate не ослаблен.
QtIFW4.8.1 vendor x64; ARM64 QtIFW4.11.0 из закреплённых исходников со static Qt6.7.2
и static compression libraries. Пробы инструментов и кеш успешны на native ARM runner.
CLI upgrade: одинаковый PATH в --root и ClipFlowUpgradeTarget; только product marker
clipflow-install.txt разрешает обновление. Данные пользователя не удаляются; пустая папка может остаться.

Финальное review выявило два Important: временный auth перезаписывал durable данные,
импорт legacy Safari/Opera GX обходил Linux normalization. Оба исправлены с RED→GREEN.
RAM key/path передаются auth child через stdin; /dev/shm приватный; прежние credentials сохранены.
Дополнительно реальные проверки выявили desktop app_id и отсутствие родителя свежего RAM test report;
оба исправлены. Ожидание queued progress в scheduler-тесте исправлено без ослабления проверки stale events.
Сбой старого macOS CI не объявлялся исправленным без журнала; новый exact-source Checks прошёл,
а native GUI XML добавлен для дальнейшей диагностики.
